# 開發者品牌宣言 (Developer Manifesto)

## 品牌定位：環境科技工匠 (The Ambient Crafter)

> **「最好的科技，是讓你忘記科技的存在。 (Good design is invisible.)」**

在一個充斥著 "AI Slop"、演算法與無止盡推播來爭奪「用戶停留時間 (Screen Time)」的時代，我們選擇回歸科技的本質：**解決問題，然後安靜退場。**

科技的目的是讓生活更便利，而不是更忙碌；是讓日常更有趣，而不是製造用完即丟的焦慮。

### 核心哲學：安靜與無感 (Ambient & Frictionless)
工具應該是隱形的。我們不刻意佔用使用者的時間，而是將功能拆解、化整為零，自然地融進生活。品牌傳遞的是「最少打擾，最大平靜」。

### 生態系 Hook 與市場護城河：寄生系統 (OS-Parasitic)
現有市場的痛點在於：**人們已經不想再下載新 App，也不想再學新介面。**
我們不與巨頭競爭「打開 App」的次數，而是「打破 App 的邊界」，將阻力 (Friction) 降到絕對的零：
- **Weeklisk**：不需要打開 App 看目標，它是鎖定畫面上的一個 Widget。
- **got_bored**：不需要特地去玩，它是駐留在動態島 (Dynamic Island) 上不期而遇的微小樂趣。
- **Make it Flow**：不需要打開轉換器，它是系統「分享選單 (Share Sheet)」裡的一個無縫外掛。
- **粒粒 (Rice Journey)**：不需要每天登入農場，它是桌面上的時間窗景，一個安靜的陪伴。

我們的絕對優勢在於：**足夠輕巧，完美融入 iOS / Android 原生的生態系。** 使用者甚至不需要意識到自己打開了 App，就已經解決了問題或獲得了情緒價值。

當使用者看到我們的名字，他們知道這不是一個龐大、喧嘩的軟體，而是一個**「只要下載一次，就會安靜地在系統底層讓生活變得更好」**的優雅工具。
