# 粒粒皆辛苦 (Rice Journey) 產品願景與設計手冊

## 一、 核心概念與體驗設計

**不是教人如何種田，而是讓都市生活者重新感受到時間、食物與土地之間的關係。**

### 1. 核心產品循環：「一年一田、一季一冊」
- **每日循環**（30秒至3分鐘）：看今天的田 → 聽一段天氣與環境聲 → 離開。
- **每週循環**：稻株明顯變化、遇見田間生物。
- **每季循環**：完成稻作週期、解鎖新地景或稻種。

### 2. 真實而不煽情的文字
避免過度說教（如「農夫很辛苦要珍惜糧食」）。
改用客觀、帶有時間感與自然韻味的白描。

### 3. 將進度視覺化，取代生硬數字
不使用進度條（如「成熟度 73%」），改用環境變化作為視覺訊號：
水位下降、稻株密度增加、葉色轉深、稻穗彎曲、遠處收割機聲、曬穀場鋪滿稻穀。

### 4. 接受自然的不完美
呈現真實農業的隨機與脆弱：強風吹倒少量稻株、長時間陰雨延後成熟、麻雀啄食、福壽螺出現、炎熱致葉尖枯黃。

### 5. 安靜的收割結尾
有別於一般遊戲的金幣噴發，收割應是一場寧靜的儀式：
音樂暫停，僅剩割稻與風吹聲。畫面轉為收割後的田，顯示經過的天數。
**最後，只出現一碗白飯。** 這就是整季的成果。

---

## 二、 MVP（最小可行性產品）規格

**MVP 目標**：用最精簡成本，驗證「擬真稻穗成長 + 氣候連結 + 情感共鳴」是否能留住使用者。
**技術選型**：Flutter + 層疊插畫 (Layered PNG/WebP) + 單一主畫面 + 本地存儲 + 本地時間。無須開發複雜後端、登入或真實天氣串接。

### MVP 核心功能
1. **中央稻株 (5個視覺階段)**：育苗 → 分蘗 → 抽穗 → 黃熟 → 收割。
2. **時間與環境光影 (4種狀態)**：早晨、下午、傍晚、夜晚。根據本地時間切換。
3. **純粹視覺陪伴**：沒有任何文字輸入框，就像桌上的小盆栽，打開 App 靜靜感受。
4. **情感收割事件**：成熟後，滿版畫面與風聲，收割後顯示一碗白飯。
5. **加速體驗模式**：為了測試，提供開發者面板快速切換天氣與生長時間。

## 三、 不建議採用的營利與遊戲化機制（反常規設計）

為維持「珍惜、等待、土地節奏」的禪意，**絕對避免**以下破壞體驗的設計：
- 插頁廣告 / 觀看廣告換水滴
- 抽卡取得稀有稻種
- 稻穗死亡後付費復活 / 付費縮短成熟時間
- 金幣、鑽石、體力值系統
- 高壓連續登入獎勵 / 「今天沒登入，稻田枯萎」的懲罰機制（如果中途放棄，可設定為稻株生長停滯，但不建議讓稻穗死亡）

## 四、 台灣文化與水稻品種多樣性

### 1. 地域性內容
不使用模糊的「古代農村」風格，應立基於台灣不同地域的真實農業文化：
- 宜蘭水田與冬山河流域 / 花東縱谷 (池上、關山) / 彰化平原與濁水溪 / 嘉南大圳 / 桃園埤塘 / 原住民族互助收穫文化等。

### 2. 台灣主要水稻品種差異
- **稉稻（蓬萊米）**：如 台南11號（全台最大宗、適應性強）、高雄139號（花東主力「醜美人」）、台農71號（益全香米，帶芋頭香）、台南16號（台灣越光米）。圓短透明，軟硬適中。
- **秈稻（在來米）**：細長，較硬鬆散，多用於米粉/炒飯。
- **南北/東西差異**：西部產量導向充實快；東部溫度低充實期長，米質細緻。一期作時間長品質佳，二期作短易受氣候影響。

### 3. 文化內容應用
在 App 中可透過解鎖「地區米故事」與「農耕知識卡」（如：為什麼叫醜美人、二十四節氣卡片）來加深文化底蘊。

## 五、 產品留存動力 (Hook) 與 互動設計 (2026/08 設計共識)

針對「現代台灣人與土地記憶斷裂」的核心痛點，我們確立了以下三大設計支柱，藉此將被動的動畫轉化為具有同理心與文化深度的體驗：

### 1. 核心 Hook：「農事日誌」筆記本
- **介面呈現**：主畫面維持極簡留白，僅在角落放置一個「農事日誌」圖示。當有新事件發生（節氣改變、天氣異象、農事階段推進）時，筆記本會微微發光提示。
- **情感敘事與知識**：打開後，呈現以「阿公 / 老農夫」口吻寫下的短篇日記。結合台灣農村俚語（如「巡水路」、「看天田」、「青黃不接」），自然地科普 24 節氣與台灣農耕歷史。
- **目標**：解決使用者「對稻田一無所知」的痛點，將等待轉化為對知識與故事的期待。

### 2. 建立同理心：「微型模擬」互動 (Micro-simulation)
- **非全自動的儀式感**：當日誌提示需要「插秧」或「除草」時，不採用單一滑動或自動完成，而是引入輕度的「微型勞動」。
- **重複與耐心**：例如畫面上出現九宮格提示點，使用者必須親自、逐一點擊來完成插秧。
- **目標**：透過這種需要一點耐心與重複的微小勞動，讓使用者不再只是旁觀者，而是真正體會「粒粒皆辛苦」的重量，建立對農夫勞動的共鳴。

### 3. 無可取代的「台灣 DNA」
- **真實氣象與在地品種**：依據使用者的真實 GPS 定位決定種植品種（如嘉南平原的「台南11號」、花東的「高雄139號」），並與台灣中央氣象署的颱風、梅雨等真實天氣連動。
- **視覺地景**：在背景場景中隱晦融入能引起共鳴的台灣鄉間元素（除了現有的白鷺鷥，未來可加入遠處的土地公廟、鐵皮屋或特有鳥類）。

## 六、 生態系寄生與終極體驗迴圈 (The UX Loop)

基於「環境科技工匠 (The Ambient Crafter)」與「零阻力 (Frictionless)」的開發哲學，粒粒的互動不該依賴使用者主動打開 App，而是完美寄生於作業系統（OS），形成一個不黏人卻極具情緒價值的 1 分鐘體驗迴圈：

### 1. 寄生系統的窗景 (OS-Native Ambient)
- **日常狀態**：粒粒平常是手機桌面（Home Screen Widget）上的一扇窗。無需打開 App，滑動桌面即可看見隨真實天氣與時間動態變化的台灣稻田。陪伴在無形中發生。

### 2. 無阻力的呼喚 (Zero-Friction Prompt)
- **事件觸發**：當節氣到來（如芒種）或需要農事操作（如除草）時，Widget 的邊緣會微微發光，浮現一個小小的提示圖示（例如一頂斗笠）。

### 3. 深層連結直達 (Deep Link to Action)
- **跳過廢話**：點擊 Widget 上的提示，App 會瞬間開啟，**跳過所有選單，直達「微型互動」畫面**。
- **微型勞動**：使用者耐心地點擊九宮格，聽著清脆的水花聲完成插秧，建立與土地的連結。

### 4. 情感與知識的交付 (Knowledge Payoff)
- **阿公的日誌**：任務完成後，「農事日誌」浮現，以老農夫的口吻交代幾句科普與人生哲理（例如：「今天芒種，這批台南11號種下去了，接下來就看天田了」）。

### 5. 優雅的逐客令 (The Graceful Exit - 反焦慮設計)
- **主動勸退**：閱讀完畢後，畫面漸暗，浮現一行字：**「今日農事已畢，田水正好，去忙你的吧。」**
- **回到生活**：畫面中央僅提供一個「回到生活」的按鈕，點擊後主動結束體驗（或引導退回桌面）。貫徹「工具解決問題後，安靜退場」的最高境界，絕對不綁架使用者的時間。
